LifeOS-Healthプライバシーポリシー利用規約

プライバシーポリシー

最終更新日: 2026年10月30日

1. 対象

このポリシーは、個人用ツール「LifeOS-Health」（以下「本ツール」）に適用されます。本ツールの利用者は開発者本人だけです。

2. 取得するデータ

本ツールは、Google Health API の次の読み取り専用スコープを使い、利用者本人の Google アカウントのデータだけを取得します。

  • googlehealth.sleep.readonly（睡眠）
  • googlehealth.health_metrics_and_measurements.readonly（安静時心拍・心拍変動）
  • googlehealth.activity_and_fitness.readonly（歩数）

3. 利用目的

取得したデータは、日ごとの集計と体調の目安となるスコアの計算にだけ使い、利用者本人の予定管理に役立てます。

4. 保存場所

集計結果は、利用者本人の Google ドライブ内のファイルに保存します。開発者が別に運営するサーバーには送信・保存しません。

5. 第三者への提供

データを第三者に提供・共有・販売しません。広告やその他の目的には使いません。

6. Google API のデータの扱い

Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

7. 削除

利用者は、Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」で本ツールのアクセスをいつでも取り消せます。保存済みのファイルは、利用者が Google ドライブから削除できます。
