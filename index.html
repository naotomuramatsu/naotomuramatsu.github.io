LifeOS-Health

LifeOS-Health は、開発者本人だけが使う個人用のツールです。一般には公開・提供していません。

何をするか

Google Apps Script 上で動き、開発者本人の Google アカウントに保存されている健康データ（睡眠・安静時心拍・心拍変動・歩数）を、Google Health API から 読み取り専用 で取得します。取得したデータは日ごとに集計し、本人の Google ドライブ内のファイルに保存して、本人の予定管理ツールで体調の目安として使います。

しないこと

  • 健康データの書き込み・変更・削除はしません（読み取り専用の権限だけを使います）。
  • データを第三者に送信・共有・販売しません。
  • 本人以外の利用者を受け付けません。

English: LifeOS-Health is a personal, single-user tool run by its developer on Google Apps Script. It reads the developer's own sleep, resting heart rate, heart rate variability and step data from the Google Health API with read-only scopes, aggregates it per day, and stores it in the developer's own Google Drive. It does not write health data and does not share data with anyone.
